# Hail Mary

## Scripting (Medium)

## Description

Dr. Ryland Grace is in a tough spot! He has been tasked with performing an experiment on some "taumoeba" (Amoebas collected in the Tau Ceti system). He needs to try to breed them to meet certain biological parameters to ensure their survival when they return to Earth. See if you can help guide the experiments to find the optimal genetic code needed and you will be rewarded!

## Challenge Overview

This challenge focuses on optimizing unknown values using feedback from a remote server that provides scores on each input. The player needs to find a way to optimize 10 different "gene" values that are randomized each time that they connect.

## Deployment

This challenge has a docker component that can be deployed with docker-compose.
